# Logitech Formation

Plateforme de formation professionnelle (Next.js) — centre de formation aux engins de chantier à Tanger.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Description |
|-------|-------------|
| `/` | Accueil |
| `/formations` | Catalogue |
| `/formations/[slug]` | Lecteur / détail formation |
| `/e-learning` | Espace e-learning |
| `/dashboard` | Tableau de bord stagiaire |
| `/admin` | Tableau de bord admin |
| `/inscription` | Formulaire d'inscription |
| `/contact` | Contact |
